SysEx Message Format

Manufacturer ID: 0x7D

Microtonal Note (12 bytes)

F0 7D 01 [trk] [note] [vel] [pitL] [pitH] [sign] [partial] [amp] F7
  • 01 = Note message type
  • trk = Track index (0-127)
  • note = Nearest MIDI note (0-127)
  • vel = Velocity (0-127, 0 = note off)
  • pitL/pitH = 14-bit pitch deviation in decicents (0.1¢ resolution, ±1638.3¢ range)
  • sign = 0 = positive, 1 = negative deviation
  • partial = Partial number (1-127)
  • amp = Amplitude (0-127)

Panic / All Notes Off (12 bytes)

F0 7D 02 00 00 00 00 00 00 00 00 F7

02 = Panic message type

Transport Sync (12 bytes)

F0 7D 03 [time0] [time1] [time2] [time3] [flags] 00 00 00 F7 (Start) F0 7D 04 [time0] [time1] [time2] [time3] [flags] 00 00 00 F7 (Stop)
  • 03 = Transport Start, 04 = Transport Stop
  • time0-3 = 28-bit time in milliseconds (max ~74.5 hours)
  • flags = Reserved for future use

Spectra

by Patrik Herman

Loading projects...

A spectral/microtonal sequencer. Every note is a spectrum of partials, and pitch comes from sound rather than a fixed grid.

  • Each note is a spectrum - every partial is its own entity
  • Edit in partial space by default, not note space
  • Change tuning and grid at any point in the piece
  • Create custom tunings, timbres, and grids - or import them
  • Live additive synthesis
  • Works with live MIDI/OSC input and output
  • Export to WAV, MIDI, MusicXML, and .scl/.tun

Interface guide, tuning systems, export formats, MIDI/OSC
